# Challenge library v0.2

Starter set for v1. Each challenge has:
**Group** = people (1, 2+, 3+, 4+) · **Time** = rough hours · **Cost** = $ (free) / $$ / $$$ · **Where** = In / Out / Either · **Pts** = points · **Level** = 🟢 Easy (≤15 pts) / 🟠 Spicy (20–30) / 🔴 Extreme (35+)

Levels were set automatically from points. Move any challenge that feels wrong. A photo adds **+5 bonus points**.

Add, edit, or delete freely. This file will later become the app's database seed.
